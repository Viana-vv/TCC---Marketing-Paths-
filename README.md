# Marketing Paths

## 📌 Sobre o projeto
O **Marketing Paths** é uma plataforma web desenvolvida com o objetivo de auxiliar **microempreendedores e pequenas empresas** na organização e aplicação de estratégias de marketing digital.  
O projeto foi desenvolvido em contexto acadêmico e foca na estruturação de informações e no gerenciamento de conteúdos de forma simples e eficiente.

## 🎯 Objetivo
Facilitar o controle e a organização de ações de marketing, permitindo que usuários registrem, visualizem e gerenciem informações relevantes para seus negócios.

## ⚙️ Funcionalidades
- Cadastro e gerenciamento de usuários (CRUD)
- Cadastro e gerenciamento de conteúdos e estratégias de marketing
- Aplicação de regras de negócio para diferentes tipos de usuários
- Interface dinâmica com uso de JavaScript
- Sistema responsivo para diferentes dispositivos

> ⚠️ Algumas páginas e conteúdos não estão disponíveis publicamente por não haver autorização para exibição de materiais (como vídeos) utilizados no projeto.

## 🛠️ Tecnologias utilizadas
- **PHP**
- **MySQL**
- **PHPMyAdmin**
- **HTML5**
- **CSS3**

## 🧠 Conceitos aplicados
- Desenvolvimento **backend e frontend**
- Operações **CRUD**
- **Regras de negócio**
- Desenvolvimento, manutenção e programação de **banco de dados**
- Validação de dados
- Responsividade e usabilidade
